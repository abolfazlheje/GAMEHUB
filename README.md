# NOVA Trading Simulator

A Persian RTL paper-trading dashboard for learning and interface prototyping.

## Features
- Responsive trading-terminal layout
- Sample asset market strip and chart visualization
- Demo buy/sell orders with virtual USD balance
- Local portfolio accounting and transaction history storage
- Mock order book and watchlist-style asset table
- Local browser persistence via localStorage

## Important
This is an educational simulator. Prices and order-book depth are generated/demo values, not live market data. Orders are not sent to an exchange or broker. No real-money trading, brokerage connection, or financial account credentials are supported.

## Run locally
Open `index.html` in a browser. For GitHub Pages, enable Pages to deploy from the `main` branch root (or use the included workflow if Actions publishing is enabled).

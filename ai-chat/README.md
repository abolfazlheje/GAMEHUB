# GAMEHUB AI

یک دستیار گفت‌وگوی فارسی و راست‌چین که در پوشه‌ای جدا از صفحه اصلی GAMEHUB قرار دارد.

## اجرا روی رایانه یا سرور Node.js

1. Node.js نسخه ۱۸ یا جدیدتر را نصب کن.
2. در پوشه `ai-chat` متغیر محیطی `OPENAI_API_KEY` را تنظیم کن.
3. اجرا:

```bash
npm start
```

4. مرورگر را در آدرس `http://localhost:3000` باز کن.

## تنظیم کلید API

کلید را فقط در متغیر محیطی سرور با نام `OPENAI_API_KEY` قرار بده. هرگز آن را در فایل HTML یا JavaScript مرورگر، مخزن GitHub یا پیام‌های چت قرار نده. در سرویس میزبانی، از بخش Environment Variables یا Secrets استفاده کن.

مدل پیش‌فرض `gpt-4.1-mini` است و با متغیر اختیاری `OPENAI_MODEL` قابل تغییر است.

## نکته انتشار

این برنامه به یک میزبان دارای Node.js نیاز دارد. GitHub Pages فقط فایل‌های ایستا را میزبانی می‌کند و نمی‌تواند `server.js` یا کلید محرمانه را اجرا کند. می‌توان رابط را در Pages دید، اما برای گفت‌وگوی واقعی باید سرور را روی یک میزبان Node.js منتشر کرد و نشانی API را متناسب با آن تنظیم کرد.
